# pr-assets —— 给市场 PR 看的图

往这里放截图，提 PR 时脚本会按文件名顺序把它们列进 PR 正文的「截图或演示」那一节，
用 `raw.githubusercontent.com` 的链接引用，钉在这次发布的 tag 上。

- 支持 `.png` `.jpg` `.jpeg` `.gif` `.webp`
- 文件名会当作图片说明显示，所以起个好名字：`01-主界面.png`、`02-PR面板.png`
- 整个 `release/` 目录出包时会被排除，这些图不会进安装包
- 上传前检查一下：别带个人信息、令牌、真实仓库路径

这里不放图也行：截图不是必填项，PR 正文里那一节会写一行「本版未附截图」，不影响发布，
也不会因此把 PR 开成 draft。
